# Design guidelines

Як виглядає і чому саме так. Живі значення токенів для активної теми — на сторінці **Design tokens** у playground (`/design`).

Джерело істини для значень: [`src/styles/tokens.css`](src/styles/tokens.css) (геометрія, типографіка, тіні), [`src/styles/colors.css`](src/styles/colors.css) (сира палітра, єдине місце з hex), [`src/styles/theme.css`](src/styles/theme.css) (ролі кольорів для light/dark).

---

## 1. Принципи

1. **Одна лінія.** Все розділяється хейрлайном `--t-color-border`, а не тінями. Тіні лишаються тільки тому, що «плаває»: попапи, тости, модалки.
2. **Дві поверхні.** Сторінка — `--t-color-bg`, все на ній — `--t-color-surface`. Третьої поверхні немає. `--t-color-surface-2` — тільки для «вдавлених» зон: код, disabled-інпут, трек segmented-контролу.
3. **Один акцент.** Теракота позначає головну дію та активний стан. Семантичні кольори приглушені й слугують лише статусу, а не декору.
4. **Ієрархія вагою, не розміром.** Body 14px. Заголовки 20 / 16 / 14 із вагою 600. Вторинний текст — `--t-color-text-muted`, а не менший кегль.
5. **Радіус за роллю.** 8px — контроли, 12px — контейнери, pill — чипи. В межах однієї сім'ї елементів радіус не змішується.
6. **Спокійні стани.** Hover — прозора плівка `--t-color-hover`, працює на будь-якій поверхні. Active/selected — м'який тінт `*-plain-bg` (12–16%), а не суцільна заливка.

---

## 2. Кольори

### Ролі (публічний API)

Компоненти й споживачі використовують **лише** `--t-color-*`. Сира палітра (`--t-warm-*`, `--t-terra-*`, `--t-oc-*`) — деталь реалізації, її можна змінити без мажорної версії.

| Роль | Для чого | Не для чого |
|---|---|---|
| `--t-color-bg` | фон сторінки, сайдбар, нав-панелі | картки, інпути |
| `--t-color-surface` | картки, інпути, попапи, таблиці, модалки | фон сторінки |
| `--t-color-surface-2` | код-блоки, disabled-інпут, трек segmented | ще одна «картка» |
| `--t-color-border` | всі лінії: рамки, роздільники, хейрлайн активного пункту | текст |
| `--t-color-border-strong` | hover на рамці, ручки перетягування | звичайні рамки |
| `--t-color-text` | основний текст, заголовки | іконки у спокої |
| `--t-color-text-muted` | підписи, мета, плейсхолдери, іконки у спокої | великі блоки тексту |
| `--t-color-hover` | hover-плівка на рядках, пунктах меню, ghost-кнопках | активний стан |
| `--t-color-backdrop` | підкладка модалок/шитів | — |
| `--t-color-accent` | primary-кнопка, лінки, активна іконка, фокус | статус, декор |
| `--t-color-accent-plain-bg` | selected/active тінт: пункт списку, segmented, plain-кнопка | фон блоків |
| `--t-color-success/-warning/-danger` | статус, деструктивні дії | акцент |
| `--t-color-*-plain-bg` | тінт статусу: теги, банери, тости | — |
| `--t-color-info` | приглушена вторинна дія (`TButton variant="info"`) | статус «інфо» |
| `--t-color-focus-ring` | 3px кільце фокуса на інпутах | рамки |

### Рецепт статусу

Статус = м'який тінт + текст того ж відтінку, змішаний з `--t-color-text`:

```css
background: var(--t-color-success-plain-bg);
color: color-mix(in srgb, var(--t-color-success) 78%, var(--t-color-text));
```

Той самий рецепт у `TTag`, тостах `TNotifications`, банерах. Не вигадуй нових комбінацій.

### Темна тема

Ролі ті самі, значення інші. Компонент не має знати про тему: якщо ти пишеш `html.dark .my-thing {}` — ти зробив щось не так, бери іншу роль.

## 3. Геометрія

### Радіуси

| Токен | px | Де |
|---|---|---|
| `--t-radius-mini` | 4 | чекбокс, inline-код |
| `--t-radius-small` | 6 | контроли `size="small"/"mini"`, focus outline |
| `--t-radius-default` | 8 | кнопки, інпути, пункти меню, попапи |
| `--t-radius-medium` | 10 | тости, випадайки, segmented-трек |
| `--t-radius-large` | 12 | картки, таблиці, модалки |
| `--t-radius-pill` | 999 | теги, бейджі, свічі |

### Відступи

Шкала 4px: `--t-space-1..8` = 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64.

- Всередині контролу: `0 var(--t-space-3)`.
- Всередині картки: header `space-3 space-4`, body `space-4`.
- Між картками на сторінці: `space-4`. Між секціями: `space-5`.
- Gap між іконкою й текстом: `space-2`. Між чипами: `space-2`.

### Висоти контролів

`--t-control-h-mini..large` = 24 / 28 / 32 / 36 / 40. Кнопка, інпут, селект і свіч одного `size` мають однакову висоту, щоб стояти в одному рядку.

### Тіні

| Токен | Для чого |
|---|---|
| `--t-shadow-1` | ледь помітний підйом: thumb свіча, активний сегмент |
| `--t-shadow-2` | попапи, випадайки, тости |
| `--t-shadow-3` | модалки, drawer |

Тінь тонується `--t-shadow-color` (текст у light, чорний у dark). Картки й таблиці тіні **не мають** — тільки рамку.

---

## 4. Типографіка

- Шрифт — системний стек `--t-font-ui`; моно — `--t-font-mono` для коду, шляхів, ID.
- Кеглі: `mini 12 · small 13 · default 14 · medium 15 · large 16 · xlarge 18`; заголовки `h1 20 · h2 16 · h3 14`.
- Ваги: `400` текст, `500` підписи/пункти меню/кнопки, `600` заголовки й активні елементи. Інших ваг немає.
- Заголовок таблиці: `--t-color-text-muted`, вага 500, кегль 0.875em від таблиці.
- Секційний заголовок у сайдбарі: `mini`, 600, uppercase, `letter-spacing: .06em`, muted.
- Бібліотека **не** стилізує `h1–h3` глобально — це зона застосунку. Використовуй токени `--t-font-size-h*`.

---

## 5. Рух

- `--t-duration` 150ms — кольори, фон, рамки.
- `--t-duration-slow` 280ms + `--t-ease` — зміна розмірів (ширина сайдбара, розгортання).
- `prefers-reduced-motion` обнуляє обидва токени автоматично.

---

## 6. Компонентні рецепти

**Картка (`TCard`, будь-який контейнер):** `surface` + `1px border` + `radius-large`, без тіні. Header відділений хейрлайном, вага 600.

**Кнопка `neutral`:** `surface` + `border`, текст `--t-color-text`. Hover — акцентний тінт. Це «кнопка за замовчуванням»; `accent` — одна на екран.

**Інпут:** `surface` + `border` + `radius-default`. Focus — рамка `accent` + `0 0 0 3px focus-ring`. Error — рамка `danger` + кільце `danger-plain-bg`.

**Пункт списку / меню:** `radius-default`, hover `--t-color-hover`, selected `accent-plain-bg`.

**Сайдбар (`TSidebar`):** на `bg`, права лінія `border`. Активний пункт — `surface` + `inset 0 0 0 1px border`, іконка `accent`. Групи — через `group` у `menuItems`; у згорнутому стані заголовок групи стає роздільником.

**Таблиця:** заголовок прозорий, muted, 500; рядки розділені `border`; hover `--t-color-hover`; selected `accent-plain-bg`.

**Тост / банер:** `surface` + `border` + `radius-medium` + `shadow-2`; статусний варіант — тінт фону і рамка `color-mix(status 35%, border)`.

**Тег / бейдж:** `radius-pill`, статусний рецепт із §2.

---

## 7. Як додати новий компонент узгоджено

1. Візьми найближчий рецепт із §6 і повтори його токенами. Жодних hex, `rgba()`, `px` для радіусів і тіней у `<style>` компонента.
2. Стани: `hover → --t-color-hover`, `active/selected → *-plain-bg`, `focus → --t-color-focus-ring`, `disabled → opacity: .5`.
3. Розміри через `size` → `--t-control-h-*` і `--t-font-size-*`, як у `TButton`.
4. Перевір у обох темах на сторінці playground. Якщо довелось написати `html.dark` — повернись до п.1.
5. Компонентні змінні (`--t-btn-*`, `--t-input-*`) — локальні, всередині `scoped`, з дефолтами з глобальних токенів.

Швидка перевірка перед комітом:

```bash
grep -nE "#[0-9a-fA-F]{3,8}\b|rgba?\(|border-radius:\s*[0-9]+px|box-shadow:\s*0 " src/components/**/*.vue
```

Винятки, які допускаються: `999px`/`50%` для кружечків, `2px` для індикаторних рисок.

## 8. Кастомізація споживачем

Перевизначай ролі, не палітру:

```css
:root {
  --t-color-accent: #2f6fdb;            /* свій акцент */
  --t-color-accent-hover: #2a62c2;
  --t-color-accent-active: #24549f;
  --t-radius-default: 6px;              /* жорсткіші кути */
}
```

Тема перемикається класами `html.light` / `html.dark` (див. `useTheme()`); тонування `color-mix` підлаштується під нові значення само.
